Privacy Policy

Last Updated: October 2, 2026

OJT AI Automation is an experimental automation application created for an academic and on-the-job training project. It is primarily intended for personal use to create and operate automation workflows using n8n and authorized Google services.

Important: OJT AI Automation only accesses Google account data after the account owner explicitly grants permission through Google's OAuth authorization process.

1. Purpose of the Application

OJT AI Automation is used to connect authorized Google services with n8n automation workflows for personal, educational, and on-the-job training purposes.

Examples of supported Google services may include Google Sheets, Google Drive, Google Calendar, Gmail, or other Google services for which the application has been explicitly configured and authorized.

2. Google User Data We Access

Depending on the specific n8n workflow and OAuth permissions granted by the user, the application may access information from authorized Google services.

For example, a Google Sheets workflow may access spreadsheet information that the user has authorized the workflow to read, create, modify, or otherwise process.

The application requests only the permissions that are necessary for the functionality of the particular workflow being used.

3. How Google User Data Is Used

Google user data is used only to perform the functions requested by the user through an authorized n8n workflow.

For example, Google Sheets data may be read by an n8n workflow, processed according to the workflow's instructions, and used to perform an automation task such as creating, updating, organizing, or transferring information.

Google user data is not used for advertising, marketing, or unrelated purposes.

4. AI and Machine Learning

If an n8n workflow is configured to use an AI or machine learning service, Google user data may be processed by that service only when necessary to perform the specific user-requested workflow.

Google user data obtained through Google Workspace APIs is not used to train or improve generalized artificial intelligence or machine learning models.

The use of raw or derived user data received from Google Workspace APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

5. Data Sharing and Transfers

OJT AI Automation does not sell Google user data.

Google user data is not shared with third parties for advertising, marketing, or unrelated purposes.

Data may be transferred to services that are explicitly included in an authorized n8n workflow when such a transfer is necessary to perform the requested automation.

For example, an n8n workflow may transfer information from Google Sheets to another service that the user has deliberately configured as part of that workflow.

Such transfers are limited to the functionality requested by the user and are subject to the applicable privacy policies and terms of the services involved.

6. Data Storage and Retention

OJT AI Automation does not intentionally store Google account passwords. Authentication with Google is performed through Google's OAuth authorization system.

Information processed by an n8n workflow may be temporarily processed or retained depending on the configuration of n8n, workflow execution settings, logs, credentials, and the individual services connected to the workflow.

The application does not retain Google user data for purposes unrelated to the operation of the authorized workflows.

7. Data Security

Reasonable technical and organizational measures are used to protect information processed through the application.

OAuth authentication is handled through Google's authorization system, and Google account passwords are not provided to or stored by OJT AI Automation.

API credentials and OAuth credentials should be stored securely and should not be publicly shared, published in source code, or exposed in public repositories.

However, no method of electronic transmission, processing, or storage can be guaranteed to be completely secure.

8. User Control and Revoking Access

Users control whether the application can access their Google account data.

Authorization can be revoked through the user's Google Account security settings at any time.

After authorization is revoked, the application will no longer be able to access the user's Google services using that authorization.

9. Data Deletion

Because OJT AI Automation is primarily intended for personal and academic use, Google user data may be removed by deleting the relevant workflow data, execution data, or other stored information from the n8n environment where applicable.

Users may also revoke the application's Google authorization to prevent future access to their Google account data.

Data that has already been transferred to another service through an authorized workflow may need to be deleted through that service's own data-management and deletion procedures.

10. Google API Services User Data Policy

OJT AI Automation's use of information obtained through Google APIs is subject to the Google API Services User Data Policy .

The application follows the applicable requirements regarding limited use, user consent, data access, data handling, and protection of Google user data.

11. Changes to This Privacy Policy

This Privacy Policy may be updated when necessary to reflect changes to the application's functionality, Google API usage, n8n workflows, or data-handling practices.

When changes are made, the updated version will be published on this page and the "Last Updated" date will be changed accordingly.

12. Contact

If you have questions about this Privacy Policy or the OJT AI Automation application, please contact: jt2304code@gmail.com
